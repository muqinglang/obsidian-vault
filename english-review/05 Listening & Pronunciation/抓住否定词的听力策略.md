# 抓住否定词的听力策略

连读会让小词变短，但 `not / didn't / isn't / wasn't / can't` 会翻转整句意义，应优先捕捉。

## 本周现象

`It's hard to think` 在自然语速中曾被听成近似 `taught to`。这是听辨现象，不是语法错误。

## 练习流程

1. 无字幕听一遍，只判断肯定还是否定。
2. 写下听到的声音，不急着猜拼写。
3. 一句一停，按意群复述。
4. 正常语速再听。
5. 最后看字幕核对。

提醒自己：`Catch the meaning, not every word.`
