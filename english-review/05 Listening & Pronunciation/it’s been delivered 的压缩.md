# it’s been delivered 的压缩

> It says it's been delivered.

自然语速中 `it's been` 会被压缩，不要期待三个词各自清楚。优先听重读部分 `delivered`。

练习层级：

1. `delivered`
2. `been delivered`
3. `it's been delivered`
4. `It says it's been delivered.`
