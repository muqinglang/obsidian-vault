# wrap up vs sum up

## wrap up

结束、收尾一项活动、谈话或会议。

> Let's wrap up the meeting by five.

## sum up

概括内容或要点。

> Let me sum up the main points before we wrap up the meeting.

## 易混

`warm-up` 是开始前的热身；`wrap up` 是结束；`end up` 是“最终结果是”。
