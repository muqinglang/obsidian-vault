# I was wondering if

非常实用的委婉请求句型，适合客服、酒店、机场和职场。

> I was wondering if you could help me rebook my connecting flight.

> I was wondering if you could tell me where you left the food.

> I was wondering if you might have marked it as delivered a little early.
